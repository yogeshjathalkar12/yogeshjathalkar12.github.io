Mac · Beta

Raptor
on Mac.

The Mac app is in beta and runs on Apple Silicon Macs. Because it is not yet signed with an Apple Developer ID, macOS asks you to approve it the first time. It takes about a minute.

What you need

Before you download.

Apple Silicon Mac

An M1, M2, M3, M4 or newer Mac. Intel Macs are not supported yet.

macOS 14 or newer

The beta is built and tested on macOS 14 (Sonoma). Older versions may not work.

Room for local AI

Raptor runs its AI on your Mac, so it works best with plenty of free memory and disk space.

Install

Five steps.

01

Download the installer

Get Raptor-0.1.1-mac-arm64.dmg with the button below. It is a large file, about 800 MB, so allow a few minutes.

02

Open it and drag Raptor to Applications

Double-click the .dmg, then drag the Raptor icon onto the Applications folder.

03

Open Raptor for the first time

Open Raptor from Applications. macOS says it cannot verify the app, because Raptor is not yet signed with an Apple Developer ID. Click Done (not Move to Trash).

04

Approve it once

Open System Settings, then Privacy & Security, and scroll to the Security section. You will see a message that Raptor was blocked. Click Open Anyway and enter your Mac password. You only do this once.

05

Allow the microphone

When macOS asks, allow microphone access so Raptor can transcribe and coach your calls. Call audio is transcribed on your Mac.

If it goes wrong

macOS says Raptor is damaged.

This is macOS being cautious about a downloaded app that is not notarized, not a sign the file is broken. Open Terminal, paste the line below, press Return, then open Raptor again.

xattr -cr /Applications/Raptor.app
Good to know

What the beta does not do yet.

Beta software

Built and checked automatically on Apple Silicon, but tested on far fewer Macs than the Windows app. Tell us what breaks.

A one-time warning

Because the app is not yet signed with an Apple Developer ID, macOS asks you to approve it once, as described above.

No automatic updates yet

Unsigned Mac apps cannot update themselves. To update, download the newest installer from this page.

One prospect source needs Edge

A company-database source uses Microsoft Edge, so it only works on a Mac that has Edge installed.

Something not working? Email contact@shoonyaorigins.com and tell us your Mac model and macOS version.
