How it works 01

Each of the five nodes listens for radar pulses. The software compares exactly when each node heard the same pulse train and works out where the emitter is, then keeps a live track of it.

01

Radio samples

From a software-defined radio, a recorded file or the built-in simulator.

02

Pulse extraction

Finds each pulse and measures its arrival time, width, power, frequency and, with two channels, bearing.

03

Sort & classify

Separates interleaved emitters and labels each by type and threat level.

04

Localise

Combines arrival-time differences across nodes to fix the emitter position.

05

Track & report

Fuses fixes into tracks, shows them on the console and prepares the encrypted report.

Safety branch   Flight and winch telemetry feeds Sentinel-Guard, which supervises the aerostat (wind, tether, helium, threats). It starts in dry-run: it shows what it would command and sends nothing until deliberately enabled.

Safety logic

Sentinel-Guard & flight link

Supervises each node using real telemetry: tether or power loss, gusts, low helium and threat radars. It declares the platform recovered only from measured altitude, and flags silent telemetry instead of acting blindly.
